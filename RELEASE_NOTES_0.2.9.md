Tabs that need you: an MCP client can now flag a tab when it needs you, for example for a CAPTCHA, a sign-in or a decision. The tab title starts with a red marker and the reason, the toolbar icon shows a red count, and the popup lists each waiting tab with Go to tab and Done buttons. The marker returns after the page reloads and disappears when you press Done, when the client clears it or when the tab closes. Flags are kept in memory only.

Optional desktop notifications: enable them in the popup to get a notification when a tab is flagged; clicking it opens the tab. Firefox asks for the notifications permission only when you enable this. The client can also bring a flagged tab to the front.

Includes the 0.2.8 form discovery and rich-text editing improvements. Existing website approval, strict single-target matching and single-shot actions remain in place.
