Form discovery and rich-text editing: file inputs hidden inside a visible drag-and-drop area can now receive an explicitly chosen file, when that area holds exactly one file input. Custom dropdown items (for example searchable resume, country or location lists) are now listed as options and can be clicked. Unlabeled questions show the text of their question container, and links report their address without query strings or fragments.

Rich-text editors that track the selection asynchronously (such as Lexical-based editors) now receive text after their selection is known, and the extension confirms that the editor kept the text. No new permissions, website access or credential handling. Existing website approval, strict single-target matching and single-shot actions remain in place.
