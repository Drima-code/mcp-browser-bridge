Right-click menus: some websites show their own menu when you right-click something, for example to pick a category for a highlighted word in an annotation tool. The client can now right-click one item on an approved page, with the same safeguards as a normal click: exactly one visible target, no password or disabled fields, one attempt and no automatic retry. The website's own menu then opens and the client can pick an entry from it. Firefox's own right-click menu never opens this way, and the client is told when the page showed no menu of its own.

This version also includes everything from 0.3.4 (page dialogs no longer freeze the connection, a tool to list and answer them, and short pauses before and after actions), in case 0.3.4 was not installed.

Everything else is unchanged. Website approval, password-field filtering, strict single-target matching and single-shot actions remain in place.
