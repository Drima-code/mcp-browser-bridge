Close finished tabs: an MCP client can now close a website tab it no longer needs, such as a job listing after the application is sent. It can only close tabs it is already allowed to use (approved tabs, or all website tabs in automatic mode); private windows and Firefox pages stay out of reach. Closing a tab also removes its attention flag. No new permissions.

Includes the 0.2.9 attention flags and the 0.2.8 form discovery and rich-text editing improvements. Existing website approval, strict single-target matching and single-shot actions remain in place.
