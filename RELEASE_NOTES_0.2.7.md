Optional Google account selection: added a popup setting, off by default, that allows the MCP client to click an existing account on approved accounts.google.com chooser pages. The choice persists across restarts and can be disabled at any time. The native client cannot enable it. Passwords, verification codes and CAPTCHA remain manual. No additional Firefox permissions are required.

Also fixes verification-code filtering when Firefox does not expose the autocomplete property. Existing website approval, strict single-target matching and single-shot actions remain in place.
