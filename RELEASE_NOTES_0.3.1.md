Optional screenshots: a new popup button lets the client capture the visible part of a tab it may already use, for example to check a form preview or a receipt. Browser toolbars and other windows are never captured, and only a tab currently shown in its window can be captured. Firefox asks for its "access your data for all websites" permission only when you press the button, because its screenshot function requires it; the access settings still decide which tabs the client may use. You can turn screenshots off in the popup at any time.

Everything else is unchanged from 0.3.0: agent window, keyboard input, short element references, attention flags and the earlier form fixes. Existing website approval, password-field filtering, strict single-target matching and single-shot actions remain in place.
