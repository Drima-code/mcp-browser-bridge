Agent window: in automatic access mode, an MCP client can now open pages itself. They open in one separate window reserved for the agent, never in your own windows. It can also load a page in a tab it already uses, go back or forward, reload, and close tabs it no longer needs. In manual mode it still cannot open pages.

Keyboard: clients can press one key (Enter, Escape, arrows, Backspace, Delete, Home, End, Page Up/Down, space) or type text key by key, for fields that filter as you type such as searchable resume or country lists. Simulated keys never submit forms on their own.

Shorter page readings: each form control now gets a short reference (for example e12) that stops working once the page changes, replacing long positional selectors. Page readings are much smaller and faster for the client.

Optional screenshots: a new popup button lets the client capture the visible part of a tab it may already use, for example to check a form preview or a receipt. Browser toolbars and other windows are never captured. Firefox asks for its "access your data for all websites" permission only when you press the button, because its screenshot function requires it; the access settings still decide which tabs the client may use. You can turn screenshots off in the popup at any time.

Includes 0.2.8–0.2.10: attention flags for tabs that need you, custom dropdown and drop-zone support, and reliable rich-text editing. No new required permissions; screenshots use an optional one. Existing website approval, password-field filtering, strict single-target matching and single-shot actions remain in place.
