Agent window: in automatic access mode, an MCP client can now open pages itself. They open in one separate window reserved for the agent, never in your own windows. It can also load a page in a tab it already uses, go back or forward, reload, and close tabs it no longer needs. In manual mode it still cannot open pages.

Keyboard: clients can press one key (Enter, Escape, arrows, Backspace, Delete, Home, End, Page Up/Down, space) or type text key by key, for fields that filter as you type such as searchable resume or country lists. Simulated keys never submit forms on their own.

Shorter page readings: each form control now gets a short reference (for example e12) that stops working once the page changes, replacing long positional selectors. Page readings are much smaller and faster for the client.

Includes 0.2.8–0.2.10: attention flags for tabs that need you, custom dropdown and drop-zone support, and reliable rich-text editing. No new Firefox permissions. Existing website approval, password-field filtering, strict single-target matching and single-shot actions remain in place.
